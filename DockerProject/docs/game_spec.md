# ゲーム仕様書（feature/1124-03）

これまでの実装（ガチャ・所持カード・チーム編成・対戦履歴・cron ランキング・JSON 出力）をもとにした、
**ステージ攻略型の RPG（＋他ユーザーとの対戦）**。インタビューで決めた内容をまとめる。

## 1. 全体の流れ

```
ガチャ（ガチャ石）→ カード入手・重複は自動で凸
   ↓
チーム編成（3人）
   ↓
ステージ攻略（PvE） / 対戦（PvP）… オートバトル。サーバが計算し、ブラウザで演出を再生
   ↓
報酬（ガチャ石・ゴールド・進化素材・経験値アイテム・経験値）
   ↓
育成（レベルアップ・進化）→ さらに難しいステージへ
```

| 項目 | 決定内容 |
|---|---|
| ジャンル | RPG（ステージ攻略） + 他ユーザーのチームとの対戦（PvP） |
| バトル | オートバトル。サーバ（PHP）で最後まで計算し、ログ（JSON）を JavaScript で再生 |
| 演出 | カード画像・踏み込み・ダメージ数字・HPバー・スキル名表示。等速 / 2倍速 / スキップ。テキストログも表示 |
| ステージ | 1本道の5ステージ（最後がボス）。前のステージをクリアすると次が解放。何度でも挑戦可（スタミナなし） |
| 敵 | 専用の敵キャラ（敵マスタ）。画像は各自で用意（`htdocs/images/enemies/`）。無いときは代わりの画像 |
| PvP | takahasi・yamada・azuma にサンプルのカードとチームを持たせ、自分のチームとオートバトル。結果は対戦履歴に入り、cron のランキングに反映 |
| 追加要素 | スキル・属性・レベル/経験値・報酬（ガチャ石など） |

## 2. カード

### 2.1 属性（5種類）
エーテル / 炎 / 氷 / 物理 / 電気

- **相性は敵ごとの弱点・耐性で決まる**（味方同士の相性はない）
  - 弱点属性で攻撃: 与ダメージ **1.5倍** / 耐性属性で攻撃: **0.5倍**
- ステージ画面に敵の弱点・耐性を表示し、編成を考える遊びにする
- PvP（カード同士）では属性補正なし

### 2.2 タイプ（4種類）

| タイプ | 役割 | スキルの例 |
|---|---|---|
| アタッカー | 高い攻撃力で敵を倒す | 単体大ダメージ / 全体ダメージ |
| タンク | 敵の攻撃を引きつけて耐える | 挑発（敵の攻撃を自分に集める）＋ダメージ軽減 |
| ヒーラー | 味方を回復する | 単体回復 / 全体回復 |
| サポート | 味方の強化・敵の弱体化 | 味方全体の攻撃力アップ / 敵全体の防御ダウン |

### 2.4 レベル・経験値
- 経験値は **バトル（ステージ・PvP）** と **経験値アイテム（経験値ポーション 小/中/大）** で得る
- バトルでは出撃した3人全員に経験値。レベル上限に達したら、それ以上はたまらない
- 次のレベルまでの必要経験値: `10 × 現在のレベル + 20`
- ステータス: `基礎値 × (1 + 0.03 × (レベル − 1))` に、凸のボーナスを掛ける

### 2.5 進化（レベル上限アップ）
進化 ＝ レベル上限の段階を上げること（既存の「強化」画面は廃止）。

```
Lv20 到達 → 進化1 → Lv30 到達 → 進化2 → Lv40 到達 → 進化3 → Lv50 到達
                                                    → 3凸で上限 55 → 5凸で上限 60
```

| 進化 | 条件 | 上限 | 必要なもの |
|---|---|---|---|
| 進化1 | Lv20 | 20 → 30 | そのカードの属性の結晶 ×3、ゴールド 1000 |
| 進化2 | Lv30 | 30 → 40 | 結晶 ×6、ゴールド 3000 |
| 進化3 | Lv40 | 40 → 50 | 結晶 ×10、ゴールド 6000 |

結晶（進化素材）は属性ごとに5種類。ステージで入手する。

### 2.6 凸（限界突破）
- **ガチャで同じカードが出たら自動で +1凸**（カードは1種類につき1枚）。6凸で完凸
- 完凸後に同じカードが出たら **ショップメダル** に変換（UR 50 / SSR 20 / SR 8 / R 3 / N 1）
- 凸の効果（タイプによって伸びるステータス・スキルが変わる）

| 凸 | 共通 | アタッカー | タンク | ヒーラー | サポート |
|---|---|---|---|---|---|
| 1 | ステータス +5% | 攻撃 | HP・防御 | HP・攻撃（回復量） | 攻撃・防御 |
| 2 | スキル強化 | ダメージ +20% | 軽減率 +10% | 回復量 +20% | 効果量 +10% |
| 3 | Lv上限 +5（最終進化後） | | | | |
| 4 | スキルのクールタイム −1 | | | | |
| 5 | Lv上限 +5（最終進化後） | | | | |
| 6（完凸） | ステータス さらに +10%・金枠 | ダメージ さらに +30% | 挑発の持続 +1ターン | 回復量 さらに +30% | 効果の持続 +1ターン |

## 3. バトル

- 1ターンに、生きている全員が **素早さ順** に行動する
- 行動: スキルが使えれば（クールタイムが 0 なら）スキル、そうでなければ通常攻撃
  - 回復スキルは、味方の HP が 70% 未満のときだけ使う
- 攻撃対象: 味方は HP の割合が一番低い敵を狙う。敵はランダム（挑発中のタンクがいればそのタンク）
- ダメージ: `max(攻撃×倍率×0.15, 攻撃×倍率 − 防御×0.6) × 属性 × 乱数(0.92〜1.08)`
- ステージは 1〜3 ウェーブ。HP・強化効果は次のウェーブへ引き継ぐ
- 30ターンで決着がつかないとき: ステージは敗北、PvP は引き分け

### ステージのクリア評価（★）
- ★1: クリア / ★2: 誰も倒れずにクリア / ★3: 目標ターン以内にクリア

## 5. ガチャ・通貨・ショップ

| アイテム | 入手 | 使い道 |
|---|---|---|
| ガチャ石 | ステージ初回クリア、PvP 勝利、ショップ、初期 3000 | ガチャ（単発 300 / 10連 3000。ボックスガチャも同じ） |
| ゴールド | ステージ、PvP | 進化 |
| 結晶（5属性） | ステージ、ショップ | 進化 |
| 経験値ポーション 小/中/大 | ステージ（確率）、ショップ | レベルアップ（経験値 100 / 500 / 2000） |
| ショップメダル | 完凸後の重複カード | ショップでの交換 |

- **ショップ**（ショップメダルで交換）: ガチャ石・結晶・経験値ポーション・ゴールド
- **デバッグ**: 動作確認用に、ガチャ石 +10000 などを付与できる画面（`/game/debug.php`）

## 6. PvP（対戦）

- 相手: 自分以外のユーザーの、メンバーがいる最初のチーム（CPU が操作）
- 結果は `battle_histories` に保存され、cron（資料06）のランキングに反映される
- 報酬: 勝ち ガチャ石 50・ゴールド 300・経験値 150 / 引き分け ゴールド 150・経験値 100 / 負け 経験値 60
- 資料06 のランダム対戦画面は「テスト用」としてメニューに残す
