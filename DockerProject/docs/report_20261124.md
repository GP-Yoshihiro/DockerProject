## 3. ゲーム開発（feature/1124-03）

インタビューで仕様を決めて実装（詳細は `docs/game_spec.md`）。

| 項目 | 内容 |
|---|---|
| ジャンル | ステージ攻略型 RPG ＋ 他ユーザーのチームとの対戦（PvP） |
| バトル | サーバで計算するオートバトル。ログ（JSON）を JavaScript で演出として再生（等速 / 2倍速 / スキップ） |
| ステージ | 5ステージ（ボスあり）。敵ごとの弱点・耐性、★3評価、初回報酬。難易度はシミュレーションで調整 |
| 対戦 | 結果を対戦履歴に保存 → 資料06 の cron ランキングに反映 |
| カード | 5属性 × 4タイプ（アタッカー・タンク・ヒーラー・サポート）、クールタイム制のスキル |
| 育成 | レベル・経験値アイテム、進化（上限 20→30→40→50）、凸（重複で自動、3凸・5凸で上限 55・60） |
| 経済 | ガチャ石・ゴールド・ショップメダル、ショップ、デバッグ（アイテム付与） |

### 追加: 音動機・ピックアップガチャ

- **レアリティ**: Sキャラ ＞ S音動機 ＞ Aキャラ ＞ A音動機 ＞ B音動機
- **音動機**: キャラに1つ装備。汎用 / 属性汎用 / キャラ専用（ファイル名がキャラ名と同じ）の効果。専用アイテムでレベルアップ・進化、重複で自動凸
- **ガチャ**: 3種類。天井はガチャの種類ごとに引き継ぎ（200万連のシミュレーションで確認済み）

| ガチャ | S級 | 天井 | PU 確定まで（最大） | 10回目の確定 |
|---|---|---|---|---|
| Sキャラ PU | 0.6% | 90連 | 180連（PU 50%） | A級以上のキャラ |
| 音動機 PU | 1.0% | 80連 | 160連（PU 75%） | A級以上の音動機 |
| 恒常 | 0.6% | 90連 | — | A級以上 |

- **画像**: `htdocs/images/zzz/`（icon・standing pose・sound engine）に対応
- **登録画面**（`/game/admin.php`）: zzz の画像を選んでキャラ・音動機を登録し、ピックアップを設定
  - 画像が既存の市販ゲームのキャラのため、キャラデータは登録画面から各自で登録する
- **一括登録画面**（`/game/admin_bulk.php`）: 未登録のアイコン（25人）を表に並べ、ボタン1回でまとめて登録
  - 行ごとに S/A・属性・タイプ・スキル名を選ぶ（スキル名は空欄なら「名前のスキル」）。選んだ行にまとめて同じ値も設定できる
  - 立ち絵・専用音動機は同じ名前のファイルを自動で選択（`Anbie` / `Ambie` のような1〜2文字の打ち間違いも候補にし、「≈」で表示）
  - 入力に誤りがある行はエラーを表示して飛ばし、他の行は登録。同じアイコンの二重登録は防ぐ
