# 敵キャラの画像

このフォルダに、次のファイル名で敵キャラの画像（PNG）を置いてください。
画像が無いときは、代わりの画像（`/images/cards/no_image.svg`）が表示されます。
※ サーバー（Linux）では大文字・小文字が区別されるので、ファイル名は正確に合わせてください。

| ファイル名 | 敵 | 出現ステージ |
|---|---|---|
| slime.png | スライム | 1 始まりの草原 |
| ice_bat.png | アイスバット | 2 凍てつく洞窟 |
| frost_wolf.png | フロストウルフ | 2 凍てつく洞窟 |
| scrap_drone.png | スクラップドローン | 3 廃工場 |
| iron_golem.png | アイアンゴーレム | 3 廃工場 |
| volt_spirit.png | ボルトスピリット | 4 雷鳴の塔 |
| thunder_knight.png | サンダーナイト | 4 雷鳴の塔 |
| shadow.png | シャドウ | 5 虚無の竜 |
| void_dragon.png | ヴォイドドラゴン | 5 虚無の竜（ボス） |

追加キャラのカード画像は `htdocs/images/cards/` に置きます:
`aoi.png`（アオイ）/ `ren.png`（レン）/ `tsubasa.png`（ツバサ）/ `shion.png`（シオン）/ `yuzuha.png`（ユズハ）
